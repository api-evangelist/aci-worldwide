# ACI Worldwide — Open Payment Platform (PAY.ON gateway)

> ACI Worldwide (NASDAQ: ACIW) is a US-headquartered payment-software company. Its API-native surface is the ACI Open Payment Platform (the PAY.ON global payment gateway on oppwa.com): a unified RESTful API for accepting and managing card and alternative-payment transactions. Requests are authenticated with an Authorization Bearer access token plus a channel `entityId`; server notifications are delivered as AES-256-GCM encrypted PAYMENT/REGISTRATION/SCHEDULE/RISK webhooks. Production host https://eu-prod.oppwa.com, test host https://eu-test.oppwa.com.

## APIs
- [Server-to-Server API](https://docs.aciworldwide.com/integrations/server-to-server): Core REST payment API — preauthorization (PA), debit (DB), capture (CP), refund (RF), reversal (RV) over POST /v1/payments and GET /v1/payments/{id}.
- [COPYandPAY widget](https://docs.aciworldwide.com/integrations/widget): SAQ-A embedded card/alt-payment form loaded via /v1/paymentWidgets.js.
- [BackOffice API](https://docs.aciworldwide.com/integrations/backoffice): Post-authorization capture, refund and reversal management.
- [Pay By Link](https://docs.aciworldwide.com/integrations/paybylink): Hosted payment link pages.
- [Mobile SDK](https://docs.aciworldwide.com/integrations/mobile-sdk): iOS/Android in-app payments with tokenization and 3-D Secure.
